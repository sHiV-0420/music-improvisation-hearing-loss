# Music Improvisation for Hearing Loss

Audio enhancement system using the MUSDB18 dataset to assist listeners with hearing loss.

## Features
- Source separation (vocals, drums, bass, other stems)
- Hearing loss profiles: mild, moderate, severe
- EQ-based frequency enhancement
- Dynamic compression

## Setup
1. Mount Google Drive with MUSDB18 dataset
2. Run cells in order
3. Use the interactive widget to select a profile and enhance audio

## Dataset
[MUSDB18](https://sigsep.github.io/datasets/musdb.html)
